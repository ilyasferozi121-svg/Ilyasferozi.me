## Publish with GitHub Pages
1. Replace the contents of the target repository with the contents of this folder. Do not upload the original production-kit ZIP, review files, source CVs, private asset manifest, or excluded certificate originals.
2. In GitHub, open **Settings → Pages** and select **GitHub Actions** as the source.
3. Push to `main`. The workflow publishes the static site from the repository root.
4. Check the published site, certificate links and domain configuration.

The repository previously contained a `CNAME` file for `opinehub.live`. This package intentionally does not include a CNAME file: keep that domain only if it is yours and is the domain you want this portfolio to use. Otherwise configure a domain you control in GitHub Pages after updating DNS.
